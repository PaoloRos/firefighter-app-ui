# Skills for repetitive work

## Update TODO.md with new tasks

Update the `TODO.md` file with new tasks as they are defined. Ensure that each task has a unique identifier, title, and `Ask`. Verify that the tasks are sequentially numbered and do not reuse or renumber existing identifiers.

The content of the tasks is the one selected in the prompt, and the agent should not create tasks, rewrite asks, or infer work items. After adding a task, confirm that it exists in the `TODO.md` file.
