# Event Guideline for AI

The calendar reference is [taschenkalendar-2026.pdf](data/taschenkalendar-2026.pdf). The employment reference is [list-users.json](data/list-users.json).

* Create the event plan in **.xlsx** and save it in `/assets/year-2026/`

* Start from the month of **October**

* inside each weeks are written the names of who has the shift during that week

* in this period the shif starts on monday and finishes on the next monday. The shift is during only the night from 22:00 to 07:00.

* everybody events: **uebung** (20:00 - 21:00), **weihnachtsfeier** (all-day)

* only `atemschutztraeger`: **atemschutz** (20:00 - 21:00)

* **sitzung** (20:00 - 21:00) events only for: `ausschussmitglied`, `schriftfuehrer`, `kassier`, `geraewart`, `KDT`, `KDT-STV`, `ZKDT`, `GKDT`

* background colour of each event's whole row in the .xlsx (light shades, so the text stays readable):

  | Event | Colour | Hex |
  |---|---|---|
  | **uebung** | blue | `BDD7EE` |
  | **atemschutz** | green | `C6E0B4` |
  | **sitzung** | yellow | `FFF2A8` |
  | **weihnachtsfeier** | red | `F4B6B6` |

  Other rows, such as the night shifts, keep no background.
